# Product image sources

All assets in this directory were resized and converted to AVIF for this storefront. Product names and imagery were reviewed together; an image is never shared between unrelated product records.

## Existing project assets

The Amul milk, dahi and paneer images, brown eggs image, Coca-Cola can image and Fanta can image were retained from the application's existing Cloudinary product library and localized here. They are treated as project-supplied assets.

The Maggi product image was retained from the existing catalog's [Open Food Facts product record](https://world.openfoodfacts.org/product/8901058000290/maggi-2-minute-masala-noodles).
